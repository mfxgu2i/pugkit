# エラーと警告の読み方

## エラー表示

CLI が異常終了したときは、原因のメッセージだけを表示して終了コード 1 を返す。設定ミスや出力先の衝突など、ソースを直せば済むエラーがスタックトレースに埋もれないようにするため。

pugkit 自体の不具合を調べるときは `PUGKIT_DEBUG=1` を付けるとスタックトレースが出る。

```sh
PUGKIT_DEBUG=1 npx pugkit build
```

## ビルドが中止するもの

次の場合はビルドを続けても正しい出力にならないため、中止する。ソースを直してから再実行する。

| 中止する条件                                      | 対処                                                                        |
| ------------------------------------------------- | --------------------------------------------------------------------------- |
| `src/` と `public/` で出力先が同じになる          | どちらか一方を削除する                                                      |
| `@half` / `@<数字>w` で終わる画像名が置かれている | ビルドの予約名なので別の名前にする                                          |
| 設定ファイルに廃止されたキーが残っている          | エラーメッセージが移行先のキー名を示すので、それに従って改名する             |
| `outDir` の指定が不正                             | プロジェクトルート・`src`・`public`・`node_modules` を含むパスや、`src` / `public` の配下を避ける |

## 警告が出るもの

出力は作られるが、意図した結果になっていない可能性がある。

| 警告                                          | 意味と対処                                                                    |
| --------------------------------------------- | ----------------------------------------------------------------------------- |
| 画像が見つからない                            | パスの誤り。`src` は渡した値のまま返り、寸法は付かない                        |
| `siteUrl` が空のまま `Builder.url` を参照した | OGP や canonical に相対パスが入る。`siteUrl` を設定する                       |
| `src/` に `.webp` / `.avif` を置いた          | 出力されない。元形式（JPEG / PNG）を置いて `build.image.format` で変換する     |
| `public/` の画像に `widths` を渡した          | `public/` の画像は変換も縮小もされないため効かない                            |
| 設定ファイルに未知のキーがある                | 無視して続行する。キー名の誤りを疑う                                          |
| `build.image.format` が不正値                 | `'webp'` として続行する                                                       |
| `build.image.sourceDensity` が不正値          | `1` として続行する。既定の `2` ではないため画像の寸法が変わる                 |
| `widths` に正の整数以外を渡した               | その値を除外して続行する                                                      |

`siteUrl` の警告は、1回の実行につき1度だけ出る。共通レイアウトから参照していてもページ数だけ並ばない。

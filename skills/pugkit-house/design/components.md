# コンポーネント設計

どの層に置くかは [flocss.md](flocss.md) を参照。ここは、置き場所を決めたあとの作り方を書く。

## 子要素のサイズは親のクラスが持つ

画像やアイコンの mixin は寸法を持たない。使う側のクラスで決める。

```scss
.p-service__image {
  img {
    inline-size: 100%;
    block-size: auto;
  }
}
```

mixin 側に寸法を書くと、同じ mixin を別の場所で使えなくなる。`width` と `height` 属性はビルドが実ファイルから解決するので、手で書かない。手書きすると実寸とずれてレイアウトシフトが起きる。

## 入れ子は浅くする

BEM の要素は `__` を重ねない。`.c-card__body__title` ではなく `.c-card__title` にする。階層が深くなるほど、要素を1つ動かしたときにクラス名の付け替えが広がる。

SCSS のネストも、`&__element` の1段までにする。セレクタが深くなると詳細度が上がり、修飾子で上書きできなくなる。

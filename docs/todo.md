## 設計として保留しているもの

判断済みで、今は直さないもの。前提が変わったら見直す。

確定した設計判断は `docs/adr/` にある。ここに載せるのは「やるかもしれないが今はやらない」もので、
決定そのものではない。

| 場所                       | 内容                                                                                                                                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tasks/image.mjs`          | 画像は glob 全件走査で生成する（参照駆動にしない）。CSS の `url()` から参照される画像が dist から消える事故を避けるため。参照駆動にするなら Sass の `url()` 解析が前提になる                                  |
| `core/dev/startup.mjs`     | dev は起動時に全画像を処理する（`INITIAL_DEV_TASKS`）。実測で写真 40 枚あたり約 1.5 秒。点数の多い案件で問題になれば、Pug と同じくリクエスト時生成へ移す（[ADR 0004](adr/0004-cachedir-is-not-persisted.md)） |
| `transform/image-size.mjs` | `srcset` は密度記述子（1x/2x）のみ。レイアウト幅に応じた最適化が要件になったら w 記述子 + `sizes` を検討する（呼び出し側 API の変更を伴う）                                                                   |

## 解決済み

以下は対応が済んだため一覧から外した。

- `src/` に置いた `.webp` / `.avif` が無警告で出力されない → 全走査時に警告するよう修正（`public/` へ誘導）
- SVG・スプライトに出力先の衝突検知が無い → 検査を `core/output-conflicts.mjs` に集約し、image / svg / sprite / public を横断して見るよう修正
- `imageOptimization` に未知の値を渡すと警告なく扱われる → 値を検証して警告し `webp` に倒すよう修正
- `src` と `public` で出力先が衝突すると勝敗が非決定的 → 検知してビルドを中止するよう修正（dev は起動時に一度だけ検査してログに出す）
- `imageInfo()` が `public/` 由来の画像の拡張子を読み替え、存在しないパスを返していた → 読み替えないよう修正
- `srcset` の URL に空白・カンマが入ると候補が壊れる → エスケープするよう修正
- CLI のエラー表示がコマンドごとにバラバラ（build/sprite だけスタックトレース）→ 3 コマンドで統一し、スタックは `PUGKIT_DEBUG=1` のときだけ出すよう修正
- Pug パーシャル削除時に親ページが無効化されない → `onPugUnlink` が `removeFile` の前に影響親を取得するよう修正
- `clean()` が `sassGraph` / `scriptGraph` / `imageGraph` を残す → すべて破棄するよう修正
- `computeHash` の失敗時にランダム値を返す → 到達不能なコードごと削除
- `context.patterns` のデッドコード → 削除
